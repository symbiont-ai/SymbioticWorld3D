Version 1.0  •  5 September 2026 Page 20. Executive Summary
The project is deliberately small in cognition, rich in adaptive dynamics, and visually ambitious.
CORE PROPOSITION
What happens when embodied agents continue learning after deployment, while evolution simultaneously changes how their 
descendants learn — in a world that the agents themselves keep reshaping?
Symbiotic World is a persistent 3D artificial ecosystem built in Unreal Engine. It contains two heterogeneous populations of 
primitive learning agents: Lumen, fast bioluminescent scouts that learn and signal, and Tecton, slow ecosystem engineers that 
reshape terrain and moisture. Individuals learn online during their own lifetimes. Successful agents reproduce, and descendants 
inherit mutated meta-learning parameters. Because both populations alter the shared environment, the learning problem itself 
changes over time.
THE THREE NESTED ADAPTATION LOOPS
Lifetime scale The same individual changes its policy from experience after deployment.
Generational scaleLearning rate, exploration, memory and other meta-parameters are inherited, selected  
and mutated.
Ecosystem scaleLumen and Tecton reshape environmental conditions and therefore one another’s 
future learning problems.
Primary demoObserve one individual learn → accelerate generations → trigger drought → watch 
behavioral and evolutionary adaptation.
Final line Training was only generation zero.
Why primitive organisms are intentional
The Sundai brief does not require language models or human-level cognition. A primitive organism with a plastic policy can be a 
stronger demonstration because the audience can see exactly what changed. The hack should therefore prove a narrow 
mechanism rather than imply a sophisticated mind:
The same individual must measurably change its action policy during its lifetime.
Its descendants must inherit and mutate parameters that control how learning happens.
The two populations must change the environment experienced by future agents.
No claim of “emergent intelligence” is required; the evidence is continuous post-deployment adaptation.

DESIGN RULE
Do not present this as “a genetic algorithm with pretty creatures.” The demo must visibly distinguish within-lifetime learning 
from across-generation evolution.
Minimum proof of challenge fit
1. Select a live Lumen and display its initial action-policy values.
2. Let that same individual interact with the world for 30–60 seconds.
3. Show that its learned policy changed because of experience.
4. Show its offspring inheriting a related but mutated learning configuration.
5. Accelerate time and show a population-level shift in meta-learning parameters.
6. Trigger a drought and demonstrate adaptation continuing without offline retraining.

5. Agent Architecture
Separate inherited learning machinery from the learned policy that changes during a lifetime.
5.1 Local observable state
State vector s = [
  energy,
  nearest_resource_distance,
  nearest_water_distance,
  own_species_density,
  other_species_density,
  environment_quality,
  received_signal_or_trace
]
5.2 Action set
HIGH-LEVEL ACTIONS
FORAGE Move toward and consume a viable local resource.
EXPLORE Move toward novelty / low-visited local space.
FOLLOW Align with useful local agents or signals.
AVOID Increase distance from crowding, poor conditions or other species.
SIGNALBroadcast a local Lumen information pulse; Tecton may omit or use a simple 
orientation cue.
REST Reduce energy burn.
MODIFY Lumen deposits/updates Trace X; Tecton modifies Trace Y / terrain state.
5.3 Minimal online learner
Default hack algorithm: a contextual action-value learner. Each agent maintains a small value for each high-level action. Context  
gates impossible actions, and the agent chooses among feasible actions using an ε-greedy policy. After the action  
outcome:Q(a) ← Q(a) + α [ r − Q(a) ]
This is intentionally simpler than deep RL. It gives a stable, visible policy update that is easy to implement in Blueprints, inspect 
live, and explain to the audience.

6. Evolution of Learning
Descendants inherit the parameters that determine how they adapt — not merely a frozen final behavior.
INHERITED META-LEARNING GENOME G
α — learning rate How quickly experience updates action values.
ε — exploration rate Probability of testing a non-greedy action.
m — memory persistence How much recent experience influences behavior.
s — social responsiveness How strongly local signals / agents influence feasible-action context.
e — environmental-effect 
strengthMagnitude of Trace X or Trace Y modification.
optional γ Future-reward weighting if a Q-learning variant is implemented.
G_child = clamp(G_parent + Normal(0, σ))
Reproduction
Asexual reproduction for the hack: no mating logic or sexual recombination.
Reproduction triggers above an energy threshold and after a minimum age.
Reproduction incurs an energy cost to create selection pressure.
Offspring receive mutated meta-learning parameters and a fresh or weakly inherited policy.
The simulation logs parent ID, child ID, generation and genome values for lineage tracking.
Optional learned-policy inheritance
Only if P0/P1 are complete, initialize the child from a small fraction of the parent’s learned action values: Q_child = λ 
Q_parent + (1 − λ) Q_random   with λ ≈ 0.1
This is a stretch feature, not a dependency. The core scientific story is inheritance of learning parameters.

Version 1.0  •  5 September 2026 Page 97. Environment & Co-adaptation
Agents adapt to a world that their own behavior keeps changing.
LUMEN ACTIVITY → Trace X (decaying information field)
                     ↓
               future navigation / action context
TECTON ACTIVITY → Trace Y (soil + moisture field)
                     ↓
              resource regeneration / pathways
Both traces alter what future agents perceive, learn and select.
SHARED WORLD STATE
Resource A Primary Lumen food/resource field; locally regenerates.
Resource B Primary Tecton food/resource field; locally regenerates.
Water field Spatial availability / distance signal; strongly affected during drought.
Trace X Lumen-generated information marker with intensity and decay.
Trace Y Tecton-generated terrain/moisture modifier with slower persistence.
World update 5–10 Hz numerical update is sufficient; rendering remains independent.
Interaction principleNeither population gets a global objective to cooperate. Coupling is local and can 
produce different ecological relationships.
Why this matters
If the environment were fixed, agents would merely learn within a stationary task. Here, successful behavior changes future 
observations and resource structure, so the adaptive landscape itself moves. This is the co-adaptation layer that distinguishes 
Symbiotic World from a collection of independent learners.

Version 1.0  •  5 September 2026 Page 1412. Acceptance Criteria & 90-Second Demo
The final demonstration should be a causal story, not a montage.
12.1 Definition of done
1. Start from a known random seed and initial population.
2. Select one Lumen and show its initial learned policy and inherited meta-learning parameters.
3. Let it interact; show its policy values change in the same lifetime.
4. Show the individual reproducing or show one child with a parent ID.
5. Show the child’s related but mutated meta-learning parameters.
6. Fast-forward multiple generations; show population means/distributions shifting.
7. Trigger DROUGHT; existing individuals change behavior without offline retraining.
8. Continue fast-forward; show post-drought evolutionary change.
9. Run or show a learning-off control to demonstrate that policy plasticity matters.
10. End with the world still running: adaptation does not stop at deployment.
12.2 90-second narrative
0–15 s “Most agents are deployed when training ends. For these 
agents, deployment is when learning begins.” Show the world 
and select one Lumen.
15–35 s Show inherited parameters versus learned policy; run at 1× 
and watch the same individual update.
35–50 s Fast-forward generations. Show that descendants inherit and 
mutate how they learn, not just what they currently do.
50–75 s Press DROUGHT. Lumens regroup; Tectons alter movement; 
policy distributions shift. Accelerate again.
75–90 s Show population meta-parameter shift and control contrast. 
Final line: “Training was only generation zero.”
FINAL LINE
TRAINING WAS ONLY GENERATION ZERO.
